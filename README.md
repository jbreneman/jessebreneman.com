# jessebreneman.com

## Build Setup

```bash
# install the locked dependencies
$ npm ci

# serve with hot reload at localhost:3000
$ npm run dev

# build for production and launch server
$ npm run build
$ npm run start

# generate static project
$ npm run generate
```

Installation and production builds have been verified with Node.js 25.2.1 and
npm 11.6.2. Styles use Dart Sass (`sass`), so Python 2 and the native Node Sass
build tools are not required.

For detailed explanation on how things work, check out [Nuxt.js docs](https://nuxtjs.org).
